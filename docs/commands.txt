Embeded-Agent CLI 命令速查（agent> 提示符）

一、专注控制（结构化文本，走 RuleHandler）

  开始专注 25 分钟
  专注 25 分钟
  结束专注
  停止专注

二、Mock 状态（模拟感知，走 state_only）

  /mock presence present | away | unknown
  /mock attention focused | distracted | idle
  /mock behavior working | phone_use | staring | desk_rest | away | unknown
  /mock emotion neutral | tired | stressed | happy
  /mock fatigue none | mild | moderate | high
  /mock posture sitting | standing | leaning | lying | unknown
  /mock activity studying | working | resting | unknown

  说明：自然语言对话请用语音（/voice_once）或代码注入 speech_recognized；
  环境传感器读数需 ESP32 适配器或事件注入（见 docs/testing/agent_functional_test_guide.md）。

三、用户画像（UserProfile，权威显式数据）

  /users
  /profile
  /switch_user <user_id> [显示名]
  /set_info age 12
  /set_info gender 女
  /set_info identity 小学生
  /set_info hobbies 画画,足球
  /set_pref favorite_content_types 音乐,相声,脱口秀
  /set_pref reminder_style 温和
  /set_pref favorite_music_styles 轻音乐,古风

四、语音（需 --voice 或全栈启动）

  /voice_once          手动录一轮 → speech_recognized
  /voice_replay        回放最近一次录音

五、系统命令

  /state               完整 AgentState
  /history             最近事件与消息
  /help                帮助
  /exit                退出

六、启动示例

  python -m src.main --llm              # CLI Agent + LLM（推荐测试）
  python -m src.main                    # 全栈（桌宠+视觉+语音）
  python -m src.main --llm --voice      # CLI + 语音

详细测试流程：docs/testing/agent_functional_test_guide.md
