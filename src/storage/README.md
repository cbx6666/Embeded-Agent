# storage

`storage/` 是持久化层，负责把运行时状态和最近记忆写入本地存储。

## 职责

- 保存当前状态快照
- 保存最近事件、最近消息和专注记录
- 为后续统计和恢复运行状态提供基础

## 文件说明

- `json_store.py`：将状态快照保存到 JSON 文件，当前默认写入 `data/runtime_store.json`

## 当前实现特点

- 实现简单，便于调试和查看数据
- 适合 MVP 阶段快速验证
- 不依赖数据库环境

## 后续扩展方向

- 替换为 SQLite
- 增加日志分表或分文件管理
- 支持更多统计查询接口
- 提升高频写入场景下的稳定性

存储层的目标是让上层逻辑只关心“保存和读取”，而不关心底层具体用什么介质。
